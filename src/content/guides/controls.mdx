## Choose your input setup

The official Steam description confirms mouse, keyboard, and controller play. Randwerk's press kit also describes multiple input methods, but a support statement does not tell us the exact current key or button for every action.

Use Settings → Controls where available in your installed version and check the displayed prompts. Menu labels may vary with version or language. No WASD, mouse-button, trigger, or face-button mapping is assumed in this guide.

Likewise, controller support on Windows is not proof of a console release or a particular Steam Deck certification. Those are separate claims requiring their own confirmation.

</section>

## Separate steering from equipment use

The game emphasizes vehicle maneuvers and ability timing. Establish the movement response first, then test the actions shown for your equipment. Being able to navigate a menu does not demonstrate that every combat action is mapped as you expect.

Official notes distinguish module automatic attacks from active abilities.

Start in a situation where you can observe one action at a time. For practical first-run priorities, continue with the [beginner guide](/guides/beginner-guide/).

</section>

<section className="step-card" id="step-3">

## The alternative controller driving style

Hotfix 0.9.8 added an alternative controller driving style. If the default response is uncomfortable, this is a option worth looking for.

Change one setting and repeat the same simple maneuver. If the new style feels better, keep it while learning rather than repeatedly changing both settings and equipment. This is troubleshooting advice, not a claim about hidden input parameters.

</section>

## Handling can change with vehicle, captain, or patch

Hotfix 0.9.9 revised earlier-level driving for both [Tower](/database/vehicles/tower/) and [Spider](/database/vehicles/spider/), while also weakening Spider speed upgrades. It corrected a reverse/forward multiplier. These are reasons an older clip can look different without either player using the wrong binding.

Captain rules can also matter. Tankbert has a Nitro-regeneration penalty and Duelist a drawback while boosting. A slower recovery or a punishing boost may be part of a selected rule rather than a device malfunction.

The 0.9.8 notes also changed when Nitro regeneration begins after a boost. Check the relevant [update](/updates/#hotfix-0-9-8) before relying on older boost-spamming advice.

</section>

## Steam Input notes

Valve's Steam Input system can translate a controller's physical inputs into game inputs using a configuration. A community configuration is a player's mapping, not automatically a developer recommendation or a complete match for the current game version.

If a mapping behaves unexpectedly, inspect which configuration is active and compare it with the in-game prompts. A remapped keyboard action can display differently from a native gamepad action. This general Steam Input behavior is by Valve; no particular Wanderburg API integration is claimed here.

Avoid changing several mapping layers at once while troubleshooting. First identify the active setup, then test a single action.

</section>
